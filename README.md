# Placement Management System

A Java-based Placement Management System developed to manage
student and company placement information.

## Features

- Add Student
- Add Company
- View Students
- View Companies
- Search Student
- Update Placement Status

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Scanner

## Project Description

This project helps colleges manage student placement details
and company information in a simple and efficient way.

## How to Run

Compile the program:

javac PlacementManagementSystem.java

Run the program:

java PlacementManagementSystem
